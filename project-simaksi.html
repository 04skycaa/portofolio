E-SIMAKSI: DIGITALISASI PENDAKIAN GUNUNG BUTHAK VIA KUCUR

Semester 3 Mobile Web Android

Tentang Proyek

Kami membangun ekosistem digital terpadu yang memanjakan Pendaki sekaligus memudahkan Pengelola Basecamp Kucur.

📱 1. MOBILE APPS (Spesifik Pendaki)

Jalur Kucur dalam genggamanmu!

  • Booking Tiket Via Kucur Online: Amankan slot pendakianmu dari rumah. Datang ke basecamp tinggal scan, validasi, dan gas nanjak!
  • Info Jalur Terupdate: Dapatkan info cuaca dan kondisi real-time spesifik di jalur Kucur demi keselamatan.
  • UI Modern & User Friendly: Pengalaman persiapan nanjak yang belum pernah kalian rasakan sebelumnya.

💻 2. WEB ADMIN (Spesifik Pengelola Basecamp)

Manajemen profesional untuk Basecamp Kucur!

  • Dashboard Monitoring: Pantau trafik pendaki naik-turun via Kucur secara akurat.
  • Validasi & Keuangan: Verifikasi data pendaki dan kelola pemasukan basecamp secara transparan dan otomatis.
  • Pusat Komando: Kelola berita dan pengumuman penting seputar jalur Kucur dengan sekali klik.
