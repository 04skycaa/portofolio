E-Simaksi Gunung Butak

Web App PHP Native Management System

1. Project Apa Ini?

Web ini adalah Sistem Informasi Manajemen Akses Konservasi (SIMAKSI) Pendakian Gunung Butak secara online. Proyek ini dibangun menggunakan PHP Native, dipadukan dengan HTML, CSS kustom, dan Vanilla JavaScript. Web ini difungsikan sebagai platform lengkap, mulai dari media informasi (landing page), pendaftaran pendaki, hingga panel manajemen bagi petugas basecamp.

2. Role (Peran) Apa Saja yang Ada?

Terdapat 2 Role (Peran) Utama pada sistem ini:

  • Pendaki / Pengguna Umum (User): Masyarakat umum atau pendaki yang ingin melakukan pendakian.
  • Admin / Petugas Basecamp: Pengelola resmi atau pihak manajemen Gunung Butak yang bertugas di basecamp untuk mengatur operasional pendakian.

3. Fitur Apa Saja yang Tersedia?

🌟 Fitur Untuk Pendaki (User):

  • Sistem Auth: Registrasi, Login, dan manajemen profil pendaki.
  • Informasi Gunung: Menampilkan fakta gunung, rute akses, peta lokasi interaktif, waktu terbaik mendaki, dan keunggulan basecamp.
  • Prakiraan Cuaca Terkini: Menginformasikan cuaca 3 hari ke depan untuk persiapan keselamatan pendakian.
  • Reservasi / Booking Online: Form untuk mendaftarkan jadwal pendakian, mengisi data ketua kelompok & anggota, hingga mengunggah surat keterangan sehat.
  • Detail Transaksi: Mengecek status tiket, pembayaran (unggah bukti transfer), dan status pendakian.
  • Aksesibilitas UI: Mendukung fitur Dark/Light mode serta Toggle Bahasa terintegrasi.

⚙️ Fitur Untuk Admin (Petugas Basecamp):

Sistem Admin sangat lengkap, mencakup:

  • Dashboard Admin: Ringkasan statistik (jumlah pendaki, total reservasi, dsb).
  • Manajemen Kuota: Menutup atau mengatur batas maksimal pendaki harian agar gunung tidak overload.
  • Manajemen Reservasi: Memeriksa pendaftaran pendaki, validasi pembayaran, dan persetujuan surat sehat.
  • Manajemen Pendakian: Melakukan Check-in (saat pendaki naik) dan Check-out (saat turun) untuk memastikan semua pendaki turun dengan selamat.
  • Manajemen Pengumuman: Membuat broadcast info penting seperti cuaca buruk atau penutupan jalur.
  • Pembukuan Keuangan: Pencatatan otomatis untuk pemasukan tiket dan laporan keuangan basecamp.
  • Manajemen User: Mengelola data seluruh akun pendaki.

4. Apa Keunggulan Web Ini?

  • Desain Sangat Modern: Menggunakan desain ala Glassmorphism, gradien dinamis, animasi scroll, dan efek interaktif (seperti pulse button) yang membuatnya terasa sangat premium meski ini adalah PHP Native.
  • Berfokus Pada Keselamatan (Safety First): Terintegrasinya fitur Check-in/Check-out serta laporan cuaca membuktikan bahwa sistem ini dibuat untuk meminimalisir pendaki hilang atau overcapacity.
  • Administrasi Terpusat: Pengelola basecamp tidak perlu lagi mencatat di buku besar karena semua sistem administrasi dan pembukuan ter-digitalisasi secara rapi.

5. Web Ini Dibuat Untuk Apa?

Web ini dibuat untuk mendongkrak profesionalisme dan keamanan pengelolaan pendakian Gunung Butak melalui proses digital. Dengan web ini, pendaki bisa mendaftar dari rumah, pengelola bisa membatasi kuota harian demi kelestarian alam, dan memantau status keselamatan setiap individu/kelompok yang sedang ada di atas gunung secara real-time.
